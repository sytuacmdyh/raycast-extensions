# Base64 Text Converter Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Encode and decode UTF-8 text using standard Base64 or URL-safe Base64.
- Show conversion results as you type, with actions to copy, reverse the conversion, and clear input.
- Validate malformed Base64 and reject decoded data that is not valid UTF-8 text.
- Provide a Simplified Chinese interface on Windows and macOS.
